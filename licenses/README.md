# Licensing files

- `NOTICE.md` contains the notices displayed in-app and packaged with builds.
- `ORC-NOTICE.template.md` is a deliberately incomplete drafting template. It
  must never be shipped unchanged.

The official sources are:

- SRD 5.1 CC release: https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf
- SRD 5.2.1 release page: https://www.dndbeyond.com/srd
- CC BY 4.0 legal code: https://creativecommons.org/licenses/by/4.0/legalcode
- ORC License and AxE: https://paizo.com/orclicense

These repository documents are engineering controls, not legal advice. License
compatibility, attribution chains, trademarks, localization rights, and the
final APK notice screen require review before public distribution.
